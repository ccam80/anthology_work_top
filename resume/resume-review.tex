\section{Cubie --- GPU numerical integration}
{\small\color{muted}\href{https://github.com/cubiepy/cubie}{github.com/cubiepy/cubie}\par}
I built Cubie, an open-source Python ODE solver for consumer NVIDIA GPUs, to support
electrophysiology simulations for a real-time application.

Draft, unpublished benchmarks show \textbf{10,000$\times$ speedup}
over CPU implementations (SciPy, MATLAB) and \textbf{100$\times$}
over DiffEqGPU.jl.

\begin{itemize}
  \item I used NVIDIA Nsight Compute to guide CUDA kernel optimisation,
    changing operation ordering, memory placement, and individual instructions.
  \item I tuned occupancy to fit cache sizes and adjusted loop unrolling
    to fit the instruction cache.
  \item I instrumented internal solver stages to verify numerical
    correctness throughout the integration.
  \item I review AI-generated implementations through pull requests and
    agent sessions, identifying errors and validating numerical behaviour
    in a specialised codebase.
\end{itemize}
