\section{GPU-related}
\textbf{Cubie} -- a numerical integration/simulation suite for CUDA, through
Python.\par\vspace{1ex}
Cubie runs numerical integration kernels on domestic CUDA cards. It integrates
one system of equations per thread, a workload that is arithmetically intense
and requires wide ranges of live values. It is (traditionally) a
non-parallelisable problem, but modern GPUs can handle the per-thread load. In
my (draft, pending publishing) comparisons it offers a 10,000$\times$ speedup
over the Engineering standard numerical integrating software, MATLAB and
SciPy, and a 100$\times$ speedup over its nearest competitor, DiffEqGPU.jl
from the SciML team at MIT. Cubie kernels are JIT-compiled through
\mbox{numba-cuda-mlir}, which allows dynamic configuration of compile-time
performance tweaks like memory allocations and loop unrolling to match a
user's given problem set.
